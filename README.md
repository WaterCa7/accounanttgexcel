# Бот для ведения таблицы расходов

Вы пишете боту в Telegram как помощнику: присылаете скриншот из банка, чек или PDF и говорите, что сделать. Бот сам находит нужное место в Google Таблице, вносит запись в том же стиле, что и соседние строки, и отвечает «Готово».

Примеры сообщений:

- фото чека с подписью «ужин с делегацией»
- «добавь такси из аэропорта 17.09, 85 юаней наличными»
- «сумма там 368, я ошибся»
- «сколько сейчас итого?»
- «запомни: обеды всегда записывай как Travel - Meals and Incidentals»

Команды: `/undo` отменяет изменения последнего сообщения, `/new` начинает разговор заново, `/cost` показывает расход на Claude API за месяц.

## Что нужно для запуска

| Что | Статус |
|---|---|
| Токен бота от @BotFather | задаётся на хостинге |
| Ключ Claude API | задаётся на хостинге, переменная `ANTHROPIC_API_KEY` |
| Модель | `claude-opus-5-5`, усилие `medium` |
| Кому бот отвечает | переменная `ALLOWED_USERS` |
| Ссылка на таблицу | переменная `GOOGLE_SHEET_URL` |
| Доступ бота к таблице | шаг 1 ниже |
| Размещение на Bothost | шаг 2 ниже |

## Шаг 1. Доступ бота к таблице

Боту нужен свой служебный аккаунт Google с правом редактировать таблицу.

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) и создайте проект.
2. В разделе **APIs & Services → Library** найдите **Google Sheets API** и нажмите **Enable**.
3. В разделе **APIs & Services → Credentials** нажмите **Create credentials → Service account**, задайте любое имя и создайте.
4. Откройте созданный аккаунт, вкладка **Keys → Add key → Create new key → JSON**. Скачается файл ключа.
5. В этом файле есть строка `client_email` с адресом вида `...@...iam.gserviceaccount.com`. В таблице нажмите **Настройки доступа** и дайте этому адресу права **Редактор**.

## Шаг 2. Размещение на Bothost

Названия пунктов взяты из документации Bothost, в панели они могут немного отличаться.

1. **Зарубежный IP.** Claude API не принимает запросы с российских адресов. В профиле Bothost включите настройку «Зарубежный IP для API и нейросети». Если включить её после создания бота, бота нужно развернуть заново.
2. **Создание бота.** На странице создания выберите Telegram и Python, вставьте токен бота, источником кода укажите этот репозиторий GitHub, ветка `main`.
3. **Главный файл.** Это `main.py`, он лежит в корне репозитория. Если хостинг не определит его сам, откройте «Дополнительные настройки» и впишите `main.py` в поле «Главный файл (точка входа)».
4. **Переменные окружения.** Секреты в репозитории не хранятся, их нужно добавить в разделе «Переменные окружения»:

   | Переменная | Значение |
   |---|---|
   | `ANTHROPIC_API_KEY` | ключ Claude API |
   | `ALLOWED_USERS` | кому бот отвечает: `@имя` или числовой Telegram ID, несколько через запятую |
   | `GOOGLE_SHEET_URL` | ссылка на Google Таблицу |
   | `GOOGLE_CREDENTIALS_JSON` | весь текст файла ключа из шага 1 |

   Токен бота Bothost передаёт сам. Модель и усилие по умолчанию `claude-opus-5-5` и `medium`, их можно сменить переменными `CLAUDE_MODEL` и `CLAUDE_EFFORT`.
5. **Запуск.** Запустите бота и откройте журнал. Строка «Бот запущен» означает, что всё подключилось. Напишите боту `/start` и пришлите чек.

Для запуска на своём компьютере или сервере скопируйте `.env.example` в `.env`, заполните его и выполните `pip install -r requirements.txt`, затем `python main.py`.

Тариф: боту хватает бесплатного Starter (256 МБ памяти). На нём данные стираются при перезапуске, поэтому правила после «запомни» и счётчик `/cost` будут пропадать. На платных тарифах папка `data` сохраняется.

Обновление бота: при отправке изменений в ветку `main` Bothost разворачивает бота заново. Переменные окружения остаются.

## Как это устроено

- Ссылка на таблицу закреплена в настройках. Сам файл никуда не пересылается.
- С каждым вашим сообщением бот читает таблицу и передаёт модели её краткую текстовую карту: листы, заполненные ячейки, формулы. По ней модель понимает, куда и как писать.
- Модель правит таблицу инструментами: прочитать диапазон, записать в ячейки, вставить строки, найти текст, запомнить правило.
- Занятую ячейку бот не перезапишет случайно: для замены модель должна явно это запросить. Так защищены формулы и итоги.
- Бот помнит последние 12 сообщений разговора и журнал своих последних правок, поэтому понимает «исправь там сумму».
- Правила после «запомни: …» сохраняются в файл `data/notes.md` и действуют всегда.
- Память разговора и возможность `/undo` сбрасываются при перезапуске бота. Правила и таблица сохраняются.

## Настройка

Переменные окружения:

- `GOOGLE_SHEET_URL`: ссылка на таблицу. Чтобы переключить бота на другую таблицу, замените ссылку и дайте служебному аккаунту доступ к ней.
- `ALLOWED_USERS`: кому бот отвечает. Можно указать `@имя` или числовой ID, несколько через запятую. Числовой ID надёжнее: имя пользователь может сменить. Свой ID бот покажет по команде `/start`.
- `CLAUDE_MODEL`, `CLAUDE_EFFORT`: модель и уровень усилия. `claude-sonnet-5-5` стоит вдвое дешевле.

Файл `settings.py`: часовой пояс, длина памяти разговора, размер карты таблицы, цены для команды `/cost`.

После правок отправьте изменения в репозиторий.

## Сколько стоит

Замер на копии вашей таблицы, `claude-opus-5-5`, `medium`: сообщение со скриншотом около 5 центов, текстовое около 3 центов. Стоимость растёт вместе с таблицей, потому что её карта передаётся с каждым сообщением. Фактический расход показывает `/cost`.

## Если что-то не работает

| Сообщение | Что сделать |
|---|---|
| «Не найден файл ключа Google» | Добавьте переменную `GOOGLE_CREDENTIALS_JSON` с текстом файла ключа |
| «Нет доступа к таблице» | Дайте права редактора адресу из `client_email` |
| «Claude API отказал в доступе (ошибка 403)» | Включите в профиле Bothost «Зарубежный IP для API и нейросети» и разверните бота заново |
| «Ошибка 429» | Закончился баланс в Claude Console или превышен лимит |
| Бот молчит | Он отвечает только тем, кто указан в `ALLOWED_USERS` |
